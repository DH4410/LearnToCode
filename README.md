# Story Code Lab

Story Code Lab is a kid-friendly coding playground built with Next.js for easy Vercel hosting. Kids type sentence-style commands, see them translated into JavaScript, and solve progressive missions like `2 Sum`.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repo into Vercel.
3. Deploy with the default Next.js settings.

## What is included

- A VS Code-inspired learning interface with a playful kid-friendly look
- Sentence-based coding commands such as `make`, `set`, `show`, `add`, and `push`
- Progressive missions with local progress saving in the browser
- A generated JavaScript panel, console output, and variable inspector
